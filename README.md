# za-donut-auto

Switch 2 版『Pokémon LEGENDS Z-A』（DLC）のドーナツ厳選を自動化するツール。
ドーナツを作ってパワーを読み取り、外れならバックアップから読み込み直して作り直す。
当たりが出たらポケモンセンターで回復してバックアップを取り、Discord に報告する。

操作はすべて Python + OpenCV で動く（AI は使っていない）。1 回の試行は約 55 秒。

## しくみ

```
Switch 2 ──HDMI──▶ キャプチャボード ──▶ OBS（仮想カメラ）──▶ PC（OpenCV で画面判定）
   ▲                                                              │
   └──── Bluetooth（プロコンとして接続）──── Pico W ◀──USB シリアル──┘
```

- **Pico W**：[PicoSwitchController](https://github.com/Wilstride/PicoSwitchController) ファームウェアで Pro コントローラーになりすまし、PC からのコマンドでボタンとスティックを動かす。
- **画面判定**：実機のスクショから切り出したテンプレート（`templates/`）と画面を照合して、各段階で想定した画面になったかを確かめながら進む。
- **パワーの読み取り**：結果画面のパワー欄 3 行から「どうぐパワー：きのみ」と「どっさりパワー」の行を探し、直後のレベルの数字を読む。

## 手順の流れ

1. ソフトを終了 → 起動 → タイトルで X + B + ↑ →「バックアップで始める」
2. マップからホテルZ にファストトラベル → ドアから入ってカウンターのアンシャへ
3. きのみを選ぶ（いじげんロゼル ×6、いじげんカシブ ×2）→ +Lv と kcal で選び間違いがないか確認 → 作る
4. 結果画面のパワーを判定
   - **外れ** → 1 に戻る
   - **当たり**（きのみ Lv.2 以上 かつ どっさり Lv.3）→ Discord に結果画面ときのみの残り個数（あと何個作れるか）を送り、そのままバックアップへ
5. 結果画面を閉じる → ポケモンセンター：ベールへファストトラベル → 「休ませる」で回復（バックアップが取られる）→「レポート中」が消えるまで待つ
6. Discord で「続ける / きのみがなくなるまで続ける / 止める」を聞く。「きのみがなくなるまで続ける」を選ぶと以後は聞かず、レシピのきのみが 1 個分を下回ったら止まる

詳しい手順は [making-donut.md](making-donut.md)、開発の経緯は [ROADMAP.md](ROADMAP.md)。

## 必要なもの

- Switch 2 と『Pokémon LEGENDS Z-A』（DLC）
- Raspberry Pi Pico W（ファームウェアの書き込み手順は [docs/firmware-build.md](docs/firmware-build.md)）
- HDMI キャプチャボード（1920×1080）と OBS Studio
- Windows PC と Python 3.11
- Discord（任意。無くてもアラーム音で知らせる）

## セットアップ

```
pip install -r requirements.txt
```

1. Pico W を PC に USB で挿し、Switch の「コントローラー」→「持ちかた/順番を変える」でプロコンとして接続する。
2. OBS でキャプチャボードの映像を出し、「仮想カメラ開始」を押す。
3. Discord で通知を受けるなら、[docs/discord-setup.md](docs/discord-setup.md) の手順で `discord.json` を作り、`python tools/discord_test.py` で確認する。
4. ゲームのセーブを準備する。ポケモンセンター：ベールでバックアップを取っておく（バックアップから読み込むとそこから始まる）。

## 使い方

Switch を HOME 画面（ZA にカーソル）またはゲーム中にしておき、次を実行する。

```
python tools/run.py --device "OBS Virtual Camera"
```

| オプション | 内容 |
|---|---|
| `--max N` | N 回試行したら終わる（既定は無制限） |
| `--no-discord` | `discord.json` があっても Discord を使わない |
| `--no-alarm` | Discord を使わないとき、当たりや停止でアラームを鳴らさない |
| `--until-out` | 最初から「きのみがなくなるまで続ける」で動かす |
| `--debug` | デバッグモード。ログファイルと画面を手元に残す（下記） |

止めるときは Ctrl+C。

通常は手元に何も残さない。ログは画面に出すだけで、当たりやバックアップ完了の画面は Discord に送った後で消す。
`--debug` を付けると、`logs/` にログファイル（各段階の所要時間などの詳細も）を、`screenshots/results/`（当たり）・`screenshots/backups/`（バックアップ完了）・`screenshots/errors/`（失敗したとき）に画面を残す。

### 止まる・聞かれるとき

| 状況 | 動き |
|---|---|
| 当たり / 数字が読めない行がある（要確認） | Discord に通知してバックアップし、「続ける / きのみがなくなるまで続ける / 止める」を聞く |
| きのみが 1 個分を下回った | バックアップ後に Discord に通知して停止 |
| 昼夜の切り替わりの演出が入った | 演出が終わるのを待ってホテルZ からやり直す。Discord で「バックアップを取り直すか」を聞く（10 分返事がなければ取り直さない） |
| 想定外の画面で止まった | ソフトを終了して最初からやり直す。3 回続いたら停止して Discord に通知 |
| バックアップの途中で失敗 | 状態が分からないので自動ではやり直さず、停止して Discord に通知 |

## 注意

- **ポケモンセンターで話しかけるとバックアップが上書きされる。** ドーナツは作った時点でオートセーブされるので、当たり以外でバックアップを取ると外れのドーナツが残る（当たりが消えることはない）。
- **Pico を抜き挿しすると再ペアリングが必要。** ファームウェアが起動のたびに Bluetooth アドレスを変えるため。接続が切れて入力が届かなくなったときも「持ちかた/順番を変える」で再接続する。
- **OBS を閉じない。** キャプチャボードは OBS が掴んでいるので、仮想カメラ経由で取り込んでいる。
- ファームウェアの癖として、`PRESS` コマンドは Switch に届かず、スティックの初期値は端（倒しっぱなし）になっている。`za_donut/pico.py` が HOLD → RELEASE で押し、接続時にスティックを中央へ戻して対処している。

## 構成

```
za_donut/
  pico.py       Pico W へのシリアルコマンド（ボタン、スティック）
  screen.py     キャプチャ（最新フレームだけを保持する読み取りスレッド付き）
  vision.py     テンプレートの定義と画面判定、パワーの読み取り
  runner.py     手順の各段階（起動、移動、きのみ選択、作成、バックアップ）
  notify.py     Discord への通知とボタンの受け取り
  steps.py      調整用の値と、1 ステップずつ試すための操作
tools/
  run.py           自動厳選の本体
  run_step.py      1 ステップずつ実行してスクショを撮る（調整用）
  make_templates.py  スクショからテンプレートを切り出す（座標は vision.py の SPECS）
  make_count_digits.py  きのみの残り個数を読むための数字の見本を作る
  capture.py       キャプチャのプレビューとスクショ保存
  pico_console.py  Pico に手でコマンドを送るコンソール
  discord_test.py  Discord の接続テスト
templates/      画面判定用のテンプレート画像
docs/           ファームウェアのビルド手順、Discord の設定手順
```

## 別のレシピにするとき

狙うパワーやきのみを変えるときは、次を書き換える（今は設定ファイル化していない）。

- `za_donut/runner.py` の `make_donut()`：きのみを選ぶカーソル移動と回数。`RECIPE_BERRIES`：使うきのみ、選び終えた画面での行の位置、1 個に使う数
- `za_donut/vision.py`：`order_recipe1`（選び終えた画面の +Lv / kcal）、`power_*` と `PowerResult.hit`（当たりの条件）
- テンプレートを足したら `python tools/make_templates.py` で `templates/` を作り直す（切り出し元のスクショは `screenshots/steps/` にあり、git 管理外）
